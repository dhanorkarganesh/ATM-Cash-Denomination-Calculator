# 🏧 ATM Cash Denomination Calculator (Java)

A simple Java console-based mini project that simulates how an ATM distributes cash into different currency denominations during a withdrawal.  
This project demonstrates the practical use of **arrays** and basic programming concepts using a real-life banking scenario.

---

## 📌 Project Overview

When a user withdraws money from an ATM, the machine breaks the total amount into available currency notes such as ₹2000, ₹500, ₹200, and ₹100.  
This program accepts a withdrawal amount from the user and calculates how many notes of each denomination are required.

The project is designed for **beginners learning arrays in Java** and is suitable for **college practicals and mini projects**.

---

## 🎯 Objectives

- To demonstrate the use of arrays in Java
- To apply real-life ATM logic in programming
- To calculate currency denomination breakdown
- To improve understanding of loops and arithmetic operations

---

## ✨ Features

- Accepts withdrawal amount from the user
- Uses an array to store ATM currency denominations
- Calculates the number of notes for each denomination
- Displays a clean and easy-to-understand output
- Simple logic and beginner-friendly code

---

## 🧠 Concepts Used

- One-dimensional arrays
- `for` loop
- Arithmetic operators (`/`, `%`)
- Conditional statements
- User input using `Scanner`

---

## 🛠 Technologies Used

- **Language:** Java  
- **IDE:** Any Java-supported IDE (VS Code, Eclipse, IntelliJ, etc.)
- **JDK Version:** JDK 8 or above
